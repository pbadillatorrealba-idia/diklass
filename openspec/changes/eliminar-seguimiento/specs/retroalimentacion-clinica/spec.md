### Requirement: FR-018
**Reason**: el módulo de seguimiento (`/follow-up`) y la captura de retroalimentación clínica dejan de formar parte del producto; ninguna interfaz escribe ni lee `clinical_feedback`.
**Migration**: sin migración de datos. La base de datos conserva el tipo de registro, su validación, su inmutabilidad y su auditoría, y las filas existentes no se tocan. El ID FR-018 queda retirado y no se reutiliza.
